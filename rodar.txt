LDCN OS - executar localmente

Instale as dependencias uma vez:

python -m pip install -r apps\api\requirements.txt
cd apps\web
npm.cmd install
cd ..\..

Depois, execute backend e frontend juntos com um unico comando:

.\dev.cmd

URLs:

- Backend: http://127.0.0.1:8001
- Health check: http://127.0.0.1:8001/api/health
- Swagger: http://127.0.0.1:8001/docs
- Frontend: http://localhost:3000

Use Ctrl+C para encerrar os dois processos juntos.

Se aparecer "Backend offline", confirme:

curl.exe http://127.0.0.1:8001/api/health

O frontend usa NEXT_PUBLIC_API_URL=http://127.0.0.1:8001 por padrao.

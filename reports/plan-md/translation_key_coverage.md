# Translation Key Coverage

All four dictionaries currently contain the same 67-key set for:

- Settings and language selectors
- Topbar shell labels
- LDCN presence states and required presence messages
- Wizard-critical Blueprint, Prompt Master, and Gatekeeper actions
- Wizard step titles and descriptions
- Generated README, safety, scope, and environment descriptions

Backend validation can check arbitrary required key sets and reports missing keys separately from keys resolved through fallback.

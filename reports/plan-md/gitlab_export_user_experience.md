# GitLab Export User Experience

1. Open Settings > Integrations.
2. Enter a GitLab token and select Connect GitLab.
3. Review username, avatar, groups, project count, scopes, permission, and last sync.
4. Open a generated project and configure Repository Delivery.
5. Select Create Repository, then Export to GitLab.
6. Receive the final GitLab project URL.

The same diagnostic contract used by GitHub is applied to GitLab.

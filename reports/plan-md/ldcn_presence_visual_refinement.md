# LDCN Presence Visual Refinement

## Goal
Turn the LDCN presence into a quiet enterprise runtime indicator instead of a dominant avatar object.

## Changes made
- Reduced the orb visual weight by lowering glow, bloom, and animation intensity.
- Added an `ambient` orb mode for presence surfaces.
- Rebalanced the presence cards so operational context and registry data lead the layout.
- Moved the avatar skeleton into a smaller secondary slot and removed its central/mockup feel.
- Simplified the rail surface so the orb is contextual, not decorative.

## Visual result
- Orb is smaller and less saturated.
- Presence reads as an observer node, not a hero object.
- Content density now centers on runtime and architecture signals.

# Delivery Complexity Validation

## Estimate model

Delivery complexity is derived from architecture distribution, framework onboarding, selected capabilities, infrastructure breadth, AI/RAG paths, and Kubernetes hardening.

## Outputs

- Delivery target classification: prototype, MVP, production ready, or enterprise ready.
- Maintenance effort, onboarding effort, and deployment burden.
- Estimated weeks split into implementation, production hardening, and validation phases.

## Validation

Pytest asserts that microservices change delivery estimate relative to a modular monolith baseline.

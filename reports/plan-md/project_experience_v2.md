# Project Experience V2

## Implementado

- A rota `/projects/[projectId]` agora usa `ProjectExperienceV2`.
- A experiencia foi reorganizada na ordem solicitada: Hero, Preview, Technology Verified, Architecture Experience, Engineering Dashboard, Laboratory, Deploy Center, Documentation e Logs.
- A pagina deixou de renderizar uma sequencia longa de cards tecnicos e passou a apresentar uma jornada compacta.

## Dados Reais

Todos os indicadores sao derivados de `ProjectRecord`, arquivos gerados, preview seguro de arquivo, quality gate e status de providers Git.

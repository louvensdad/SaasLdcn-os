# LDCN Language Context Readiness

The LDCN presence layer now reflects selected language context without any AI or agent execution.

## Signals

- Java: `Observing Java ecosystem`
- TypeScript: `Observing TypeScript ecosystem`
- Python: `Observing Python ecosystem`
- Recommendations: visible in the wizard side rail as language-specific guidance

## Context updates

- `page_title` changes to a language-domain journey when a language is selected.
- `summary` uses the selected language profile summary when available.
- `pipeline.readiness_label` changes from generic observation to the selected language ecosystem.

## Scope

- No voice
- No avatar
- No generation
- No agent execution
- No AI model calls

## Outcome

The LDCN presence rail now communicates domain awareness, but stays purely informational and safe.

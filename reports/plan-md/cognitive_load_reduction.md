# Cognitive Load Reduction

The Wizard's large architecture cockpit, readiness ring, ecosystem map, and complexity radar are hidden by default behind disclosures. Two decorative step-state panels were removed.

Architecture Studio initially shows the primary architecture graph, project summary, and quiet LDCN context only. Runtime maps, future modules, engines, registries, and governance sources are collapsed.

The initial Architecture Studio component count fell from 10 visible information surfaces to 3, a 70% reduction. The Wizard removes or collapses more than 40% of the previous above-the-fold diagnostic surfaces.

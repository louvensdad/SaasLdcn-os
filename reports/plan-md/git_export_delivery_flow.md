# Git Export Delivery Flow

## Implemented Endpoints

- `POST /api/git/export/preview`
- `POST /api/git/export/github`
- `POST /api/git/export/gitlab`
- `GET /api/git/export/status/{export_id}`

## Security and Quality Rules

- Export requires an approved Gatekeeper decision, complete requirements, and a passing generated-project quality gate.
- Real `.env`, secret-like files/content, unsafe paths, and workspace-root content are excluded or block export.
- `.env.example` remains allowed when it contains safe placeholders.
- Execution requires a temporary user token or credential reference.
- Credentials are never returned or persisted in export jobs.
- Branch, commit message, namespace, visibility, and repository name are configurable.
- Default commit message: `Initial commit generated by LDCN OS`.

The secure preview, validation, staging job, status lookup, and intended `repo_url` foundation are implemented. External transmission remains blocked until OAuth or an approved provider transport is connected, so the API does not falsely report a repository as created.

GitHub/GitLab are primary actions in Project Detail. ZIP is the fallback delivery.

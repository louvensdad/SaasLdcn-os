# Secure Extensions Architecture

## Summary

User Key Boost, Git Export, and PDF Contract Input are planned secure extensions. V1 Foundation now has contracts, architecture documentation, roadmap/status visibility, and placeholder endpoints that return `501`.

No sensitive functionality is active.

## Placeholder behavior

All placeholder endpoints return:

`Feature planned but not active in V1 Foundation.`

## Extensions

- User Key Boost: temporary user AI keys, expiration, deletion, and `delete_after_generation`.
- Git Export: future GitHub/GitLab export for generated projects only.
- PDF Contract Input: future PDF upload and embedded text extraction without OCR.

## Governance

- Roadmap marks all three as `PLANNED`.
- System Status marks all three as `inactive` and `planned`.
- Security standard blocks keys, Git tokens, generated secrets, and sensitive contract text from logs, traces, ZIPs, and exports.

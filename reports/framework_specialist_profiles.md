# Framework Specialist Profiles

Date: 2026-05-20

## Scope

- Added specialist profiles for initial frameworks across Java, TypeScript, Python, C#, PHP and Go.
- Exposed backend endpoints for profile, recommended architectures, recommended capabilities, recommended endpoints and readiness.
- Connected the wizard UI and command palette to the new framework specialist surface.
- No AI, generation, voice, avatar or real agents were introduced.

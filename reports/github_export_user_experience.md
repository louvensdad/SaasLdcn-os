# GitHub Export User Experience

1. Open Settings > Integrations.
2. Enter a GitHub token and select Connect GitHub.
3. Review username, avatar, organizations, repository count, scopes, permission, and last sync.
4. Open a generated project and configure Repository Delivery.
5. Select Create Repository, then Export to GitHub.
6. Receive the final GitHub repository URL.

Recoverable states link to Connect GitHub, Reauthorize, View blockers, or Open checklist.

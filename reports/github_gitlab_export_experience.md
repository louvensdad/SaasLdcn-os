# GitHub/GitLab Export Experience

## Integração

As configurações apresentam GitHub e GitLab como integrações conectáveis com estado, usuário, avatar, namespaces, repositórios/projetos, permissões e último sync.

## Export Readiness

A área de entrega do projeto agora exibe e aplica o checklist:

- Requisitos completos
- Blueprint válido
- Arquitetura validada
- Geração concluída

A exportação permanece bloqueada até a conclusão dos quatro itens.

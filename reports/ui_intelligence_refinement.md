# UI Intelligence Refinement

## Objective

Improve the perceived intelligence of the LDCN OS frontend through visual hierarchy, subtle operational movement, and calmer responsive surfaces.

## Refinement Summary

### Hero

- Reduced visual height and empty space.
- Improved density of the operational visualization.
- Tightened text spacing and action rhythm.
- Kept the LDCN presence layer visible but less dominant.

### Cards

- Added micro operational graphs to metric cards.
- Added tiny pulse status indicators.
- Maintained consistent depth through the shared card system.
- Preserved readable text hierarchy.

### Sidebar

- Reused the established active indicator.
- Added shared microinteraction physics.
- Kept navigation scannable and calm.

### Search and Command

- Search now responds with depth, glow, and a slight desktop expansion.
- Command results inherit microinteraction response.
- Command palette keeps the ambient layer but avoids excessive motion.

### Theme Intelligence

- Emerald Matrix now behaves as an accent-led theme:
  - `--bg`: `#040706`
  - `--surface`: neutral dark green-black
  - `--glow`: reduced to `rgba(114, 220, 174, 0.13)`
  - `--accent`: `#72dcae`

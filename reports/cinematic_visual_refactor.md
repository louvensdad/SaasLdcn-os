# Cinematic Visual Refactor

## Scope
- Frontend visual and UX refactor only.
- No AI, no agents, no generation logic, no fake data.
- Existing routes, backend contracts, and data flow preserved.

## What Changed
- Introduced a reusable engineering visual system for topology, readiness, complexity, and deployment surfaces.
- Reworked the dashboard into an engineering runtime command center.
- Reframed the Wizard as an architecture journey with visible topology and layered command surfaces.
- Upgraded projects, templates, documentation, and settings into more operational registry surfaces.
- Tuned shell identity text to match the new product language.

## Notes
- The refactor prioritizes visual hierarchy, runtime presence, and adaptive density.
- Validation remained focused on type safety, build integrity, and Wizard interaction stability.

# Responsive System

## Layouts

Desktop, laptop, tablet, mobile e ultrawide possuem composição própria, não apenas escala proporcional.

## Regras

Painéis podem virar drawers; editor e preview podem alternar; console pode ser recolhido; ações críticas permanecem acessíveis.

## Critérios de aceitação

- [ ] Fluxos principais têm layout definido por breakpoint.
- [ ] Nenhum conteúdo crítico depende de hover.
- [ ] Preview permite testar viewports reais.

# Editor System Frontend

## Recursos

Split view, tabs, compare, diff, merge, readonly, live mode, AI Highlights, sugestões, Inline Chat, diagnostics, Explorer, busca e Command Palette.

## Modos

Não Programador: resultado, preview e explicação. Desenvolvedor: código, diff, logs, terminal e Git.

## Critérios de aceitação

- [ ] Alteração conversacional aponta para arquivo e linha quando possível.
- [ ] Diff é revisável antes da aplicação.
- [ ] Editor não perde estado ao alternar para preview ou chat.

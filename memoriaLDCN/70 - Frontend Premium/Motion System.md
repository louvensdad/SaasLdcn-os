# Motion System

## Objetivo

Usar movimento para comunicar causalidade e estado, nunca apenas decoração.

## Aplicações

Streaming, agente trabalhando, arquivos surgindo, progresso de build, transição de preview, dock, drag, toast e rollback.

## Regras

- Duração curta para microinteração.
- Movimento reduzido respeita preferência do sistema.
- Não bloquear interação durante animação.
- Estados críticos continuam legíveis sem movimento.

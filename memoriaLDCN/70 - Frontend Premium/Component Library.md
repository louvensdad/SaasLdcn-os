# Component Library

## Componentes base

Button, Input, Select, Table, Card, Modal, Toast, Tooltip, Popover, Tabs, Breadcrumb, Context Menu, Navbar, Sidebar, Tree e Status Bar.

## Componentes do produto

Chat, Agent Panel, Plan, Timeline, Console, Logs, Preview, Inspector, Editor, Explorer, Diff, Diagnostics, Search, Command Palette e Workspace Switcher.

## Cada componente define

Variantes, estados, teclado, acessibilidade, responsividade, tokens, eventos, loading, empty, error e exemplos.

## Critérios de aceitação

- [ ] Estados hover, pressed, loading, disabled e focus existem quando aplicável.
- [ ] Componentes não criam dependências circulares.
- [ ] Componentes de produto expõem dados e ações por contratos claros.

# Preview System Frontend

## Objetivo

Fazer o preview parecer um ambiente operacional completo, não apenas um iframe.

## Recursos

Desktop, tablet, mobile, console, logs, performance, erros, acessibilidade, network, refresh, live reload, screenshot e modo inspetor.

## Critérios de aceitação

- [ ] Preview identifica projeto, versão e build.
- [ ] Logs e erros podem ser relacionados a elementos visuais.
- [ ] Viewport pode ser alterado sem reiniciar o projeto.
- [ ] Falha de preview possui ação de retry e diagnóstico.

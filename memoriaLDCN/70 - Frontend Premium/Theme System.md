# Theme System

## Temas

Dark first, Light e High Contrast.

## Regras

Temas usam os mesmos tokens semânticos. Preferência do usuário, sistema operacional e workspace possuem precedência documentada.

## Critérios

- [ ] Componentes não dependem de valores hardcoded.
- [ ] Contraste é validado em todos os temas.
- [ ] Troca de tema não perde estado.

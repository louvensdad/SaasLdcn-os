# Layout System

## Estrutura principal

Window → Header → Workspace → Sidebar → Explorer → Editor/Chat → Preview → Inspector → Console → Status Bar.

## Layouts

- Workspace operacional
- Chat com plano lateral
- Editor dividido
- Preview com inspector
- Dashboard analítico
- Canvas de automação

## Regras

Painéis podem redimensionar, recolher e persistir preferência. O conteúdo principal nunca perde contexto ao abrir detalhes.

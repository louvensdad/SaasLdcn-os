# Interaction System

## Fluxo de criação

Mensagem → streaming → interpretação → plano → arquivos → build → preview → logs → agentes → timeline.

## Interações

Aprovar, rejeitar, editar, cancelar, retry, desfazer, rollback, comparar, expandir detalhes e pedir explicação.

## Regra

Toda ação assíncrona exibe estado, progresso, possibilidade de cancelamento e resultado.

# Dashboard System

## Objetivo

Ser um centro operacional do workspace, não uma simples lista de projetos.

## Conteúdo

Projetos, execuções recentes, custos de IA, builds, alertas, automações, atividade, incidentes, tarefas pendentes e atalhos.

## Critérios de aceitação

- [ ] Dashboard prioriza ações pendentes.
- [ ] Dados possuem período, fonte e atualização.
- [ ] Usuário consegue chegar ao contexto original de cada alerta.


O Dashboard deve exibir o status da verificação estudantil e o próximo passo quando houver revalidação necessária.

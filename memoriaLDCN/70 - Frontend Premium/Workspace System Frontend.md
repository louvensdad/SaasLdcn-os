# Workspace System Frontend

## Objetivo

Unificar workspace, projetos, conversa, arquivos, build, preview, deploy, memória, logs e consumo em uma experiência contínua.

## Estrutura

Workspace Switcher → projetos → projeto ativo → abas de trabalho → atividade e status persistentes.

## Critérios de aceitação

- [ ] Trocar workspace preserva isolamento visual e de dados.
- [ ] Projeto ativo aparece em todos os contextos.
- [ ] Usuário acessa estado, custo e atividade sem perder o trabalho atual.

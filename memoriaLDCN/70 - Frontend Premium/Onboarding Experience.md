# Onboarding Experience

## Fluxo

Entrar → escolher modo → descrever ideia → responder perguntas mínimas → revisar resumo → criar primeiro projeto → abrir preview → missão seguinte.

## Critérios

- [ ] Usuário entende o produto em poucos passos.
- [ ] Pode pular e retomar onboarding.
- [ ] Missões se baseiam em eventos reais.
- [ ] Primeiro sucesso acontece no fluxo principal, não em tour abstrato.

# Accessibility System

## Requisitos

Contraste, screen reader, teclado, foco visível, ARIA, landmarks, labels, reduced motion, tamanho de alvo, zoom e mensagens não visuais.

## Critérios de aceitação

- [ ] Fluxos principais funcionam sem mouse.
- [ ] Estado e erro são anunciados.
- [ ] Componentes passam por avaliação automatizada e manual.
- [ ] Preferência de movimento reduzido é respeitada.

# Design Philosophy

## Direção

Clareza de Linear, composição de Figma, fluidez de Notion, minimalismo de Vercel, comandos de Raycast, IA integrada de Cursor e organização de GitHub — usados como referências de princípios, não como cópia visual.

## Regras

- Uma ação principal por contexto.
- Complexidade progressiva: simples por padrão, detalhada quando solicitada.
- O sistema sempre explica estado, impacto e próximo passo.
- Densidade de informação ajustável por modo.
- Interface não deve parecer um terminal quando o usuário não é técnico.

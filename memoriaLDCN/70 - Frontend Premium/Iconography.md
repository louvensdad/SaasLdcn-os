# Iconography

## Regras

Ícones devem ter significado consistente, área de toque adequada, label acessível quando não acompanhados de texto e variantes para estado ativo, alerta e disabled.

## Critérios

- [ ] Ícone nunca é o único sinal de uma ação crítica.
- [ ] Biblioteca possui nomes e tamanhos padronizados.
- [ ] Ícones não misturam estilos incompatíveis.

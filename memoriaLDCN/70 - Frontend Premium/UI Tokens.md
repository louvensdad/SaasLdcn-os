# UI Tokens

## Cores

Primary, Secondary, Accent, Danger, Success, Warning, Information, Neutral, Surface, Background, Elevation, Border e Overlay.

## Estados

Hover, Focus, Disabled, Selection, Skeleton, Loading, Error, Success e Warning.

## Tipografia

Display, Headline, Title, Body, Caption, Code, Chat, Terminal e Monospace.

## Layout

Grid, breakpoints, espaçamentos, raios Tiny/Small/Medium/Large/XL/Pill e níveis de sombra 1/2/3/Floating/Modal/Dock.

## Motion

Curvas, duração, hover, transições, drag, dock, sidebar e dialogs.

## Critérios de aceitação

- [ ] Tokens têm nomes semânticos.
- [ ] Contraste é validado.
- [ ] Tema não exige alterar componentes.

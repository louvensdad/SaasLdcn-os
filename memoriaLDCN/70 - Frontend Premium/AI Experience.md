# AI Experience

## Objetivo

Apresentar a IA como parceira de construção, não como uma caixa de chat isolada.

## Experiência

Chat → interpretação → plano → agentes → arquivos → build → preview → logs → timeline → aprovação.

## Regras

- Streaming mostra progresso sem fingir certeza.
- Plano é editável antes da execução.
- Ferramentas e arquivos modificados são visíveis conforme o modo.
- A IA explica decisões e pede aprovação em ações de risco.

## Critérios de aceitação

- [ ] Toda resposta pode apontar para artefatos reais.
- [ ] Usuário sabe se a IA está pensando, executando, aguardando ou falhou.
- [ ] O chat não interrompe o fluxo de trabalho do projeto.

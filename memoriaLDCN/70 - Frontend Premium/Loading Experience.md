# Loading Experience

## Estados

Skeleton para estrutura, progress para tarefa mensurável, streaming para texto, typing para resposta, indeterminate para operação externa e stalled para ausência de progresso.

## Critérios

- [ ] Loading não bloqueia navegação segura.
- [ ] Operações longas mostram progresso e cancelamento.
- [ ] Stalled não é apresentado como sucesso.

# Editor visual

## Objetivo

Permitir alterações na interface sem editar código.

## Elementos editáveis

Texto, botão, cor, fonte, tamanho, espaçamento, borda, imagem, ícone, menu, formulário, posição e responsividade.

## Fluxo

1. Usuário ativa o modo editar e seleciona um elemento.
2. A plataforma identifica o componente e abre suas propriedades.
3. A alteração é aplicada ao código, testada e salva como nova versão.

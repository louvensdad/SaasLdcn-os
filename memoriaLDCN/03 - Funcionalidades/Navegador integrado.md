# Navegador integrado

## Resumo

Permite testar o sistema gerado sem sair do MLTagente.

## Fluxo

1. Dependências são instaladas automaticamente.
2. Backend e frontend são iniciados na sandbox.
3. Uma URL temporária aparece no navegador interno.
4. O usuário testa e pede alterações.
5. O preview é atualizado após validação.

## Recursos

- Voltar, avançar, atualizar e tela cheia
- Modos desktop, tablet e celular
- Captura de tela e seleção visual
- Logs e erros visíveis
- Reinício da aplicação e live reload

## Critérios de aceitação

- [ ] Abrir sem configuração manual
- [ ] Iniciar backend e frontend automaticamente
- [ ] Atualizar após alterações
- [ ] Encaminhar erros ao agente corretor

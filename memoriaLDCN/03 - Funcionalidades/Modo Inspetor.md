# Modo Inspetor

Durante o preview, o usuário clica em um elemento e vê componente, arquivo, estilos, eventos e API relacionada. Pode pedir alteração diretamente no elemento selecionado.

Exemplo: Botão “Entrar” → `LoginPage.tsx` → `PrimaryButton` → `button.module.css` → `onClick` → `/api/auth/login`.

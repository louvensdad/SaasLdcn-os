# Editor conversacional

## Objetivo

Permitir alterações por linguagem natural: “mude o botão para azul”, “adicione Pix” ou “crie uma tela de cadastro”.

## Processo

1. Identificar intenção e contexto.
2. Localizar arquivos e componentes afetados.
3. Apresentar plano de alteração.
4. Salvar a versão anterior.
5. Modificar, testar e reiniciar o preview.
6. Mostrar arquivos alterados e permitir aprovar ou desfazer.

## Regras

- Não alterar partes não relacionadas.
- Executar testes antes de publicar.
- Manter histórico e rollback.

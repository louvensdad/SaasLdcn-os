# Fluxo da edição

Usuário pede “mude o botão para azul” → IA entende → localiza componente → cria plano → salva versão anterior → edita → compila → executa testes → atualiza preview → usuário aprova ou desfaz.

Critérios: menor diff possível, arquivos modificados visíveis, teste obrigatório e rollback disponível.

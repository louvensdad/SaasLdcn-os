# Máquina de estados do projeto

Criado → Analisando → Planejando → Gerando → Compilando → Executando → Preview → Teste → Correção → Deploy → Publicado → Arquivado.

Cada transição registra responsável, evento, timestamp, versão, logs e motivo de falha. Estados de erro podem retornar para Planejando, Gerando ou Correção.

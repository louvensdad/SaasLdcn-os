# Fluxo de colaboração dos agentes

## Sequência principal

Product Owner → Analista → Arquiteto → Backend e Frontend em paralelo → QA → DevOps → Deploy.

## Paralelismo

Backend e Frontend podem trabalhar em paralelo após contrato de API e modelo de dados aprovados. Documentação pode acompanhar todas as fases.

## Bloqueios

- Backend e Frontend aguardam contratos definidos.
- QA aguarda build executável.
- DevOps aguarda artefato validado.
- Deploy aguarda aprovação e testes.

## Comunicação

Cada handoff entrega contexto, artefatos, decisões, riscos, arquivos modificados e pendências.

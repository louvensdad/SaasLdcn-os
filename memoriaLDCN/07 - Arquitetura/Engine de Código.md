# Engine de Código

Prompt → Blueprint → Plano → Lista de arquivos → Gerador → Validador → Compilador → Executor → QA → Entrega.

## Garantias

- Geração orientada por contexto real do projeto.
- Diff mínimo e rastreável.
- Validação de tipos, lint, build e testes.
- Execução em sandbox.
- Entrega somente após critérios de aceitação.

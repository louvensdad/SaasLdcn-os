# Automação como tipo de projeto

## Objetivo

Tratar automações como projetos de primeira classe, com fluxo visual, credenciais, testes, publicação e histórico de execuções.

## Exemplos

- Enviar mensagens no WhatsApp ou Telegram
- Salvar anexos do Gmail no Drive
- Copiar dados de planilha para banco
- Gerar relatórios agendados
- Integrar APIs, webhooks, FTP, CRON, Kafka, RabbitMQ e Redis

## Elementos

Gatilho, ação, condição, repetição, agendamento, integração, credencial, entrada, saída, histórico e tratamento de erro.

## Fluxo de criação

Descrição → identificação do gatilho → integrações → perguntas faltantes → fluxo visual → teste → publicação → monitoramento.

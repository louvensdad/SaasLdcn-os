# Visão do MLTagente

## Missão

Permitir que qualquer pessoa transforme uma ideia em um software funcionando, mesmo sem saber programar.

## Visão

O MLTagente será uma plataforma completa de criação, execução, teste, publicação e evolução de software com Inteligência Artificial.

## O MLTagente é

- Gerador de sistemas completos
- Ambiente de execução e testes
- Editor visual e conversacional
- Plataforma de automação
- Plataforma de deploy
- Sistema de gerenciamento de projetos
- Equipe coordenada de agentes de IA

## Objetivo final

O usuário deve sair de uma ideia para um sistema publicado sem precisar abrir VS Code, terminal ou instalar dependências.

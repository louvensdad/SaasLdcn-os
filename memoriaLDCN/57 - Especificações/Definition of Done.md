# Definition of Done

Uma funcionalidade está pronta quando:

- [ ] O contrato foi definido.
- [ ] A API foi implementada.
- [ ] A persistência foi implementada.
- [ ] Os eventos foram publicados.
- [ ] Os erros seguem o contrato padrão.
- [ ] As permissões foram aplicadas.
- [ ] Existem testes automatizados.
- [ ] Os logs possuem `correlation_id`.
- [ ] As métricas essenciais foram registradas.
- [ ] A documentação foi atualizada.
- [ ] O critério de aceitação foi validado.
- [ ] A matriz de rastreabilidade foi atualizada.
- [ ] Rollback ou estratégia de recuperação foi definida.

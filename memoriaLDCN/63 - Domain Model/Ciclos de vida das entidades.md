# Ciclos de vida das entidades

## Prompt

Draft → Validated → Approved → Deprecated → Archived.

## Blueprint

Draft → Generated → Reviewed → Approved → Executed → Superseded → Archived.

## Projeto

Created → Planning → Building → Preview → Published → Suspended → Archived.

## Feature

Proposed → Planned → In Progress → In Review → Accepted → Released → Deprecated.

## Build

Queued → Running → Succeeded ou Failed → Retried → Cancelled → Archived.

## Preview

Requested → Provisioning → Running → Updating → Stopped → Expired → Failed.

## Change Request

Draft → Analyzed → Planned → Approved → Applying → Validating → Accepted ou Rejected → Rolled Back.

## Regra

Cada transição possui ator, evento, timestamp, motivo, versão e pré-condições.

# Biblioteca de padrões

## Objetivo

Permitir que cada organização defina padrões técnicos, arquiteturais, visuais e operacionais reutilizáveis.

## Exemplos

Spring Boot, PostgreSQL, JWT, Tailwind, DDD, convenções de pastas, observabilidade e política de testes.

## Fluxo

Padrão criado → escopo definido → revisão → versão publicada → sugestão no Blueprint → aplicação → exceção justificada.

## Dependências

Blueprint, memória, governança, marketplace e sistema de aprendizado.

## Critérios de aceitação

- [ ] Padrões possuem escopo, versão, proprietário e justificativa.
- [ ] A IA sugere sem aplicar silenciosamente.
- [ ] Exceções são registradas.
- [ ] Padrão obsoleto não é aplicado a novos projetos.

# Modelo de Features do projeto

## Hierarquia

Projeto → Epic → Feature → Task → Change Request.

## Objetivo

Organizar evolução funcional sem misturar intenção, implementação e correções pontuais.

## Feature contém

Problema, objetivo, usuários, escopo, critérios, dependências, prioridade, versão alvo, métricas e riscos.

## Relacionamentos

Feature referencia requisitos, Prompt.md, Blueprint, APIs, entidades, eventos, testes e releases.

## Critérios de aceitação

- [ ] Feature pode ser planejada e liberada independentemente.
- [ ] Tasks possuem dono e dependências.
- [ ] Change Requests apontam para uma Feature ou são marcados como manutenção.
- [ ] Release mostra Features concluídas e pendentes.

# Modelo de dados

Entidades principais: Usuário, Organização, Workspace, Projeto, Arquivo, Versão, Mensagem, Tarefa, Execução, Deploy, Automação, Credencial, Evento, Métrica e Consumo de IA.

Relacionamentos preservam histórico, autoria, escopo do tenant e rastreabilidade entre pedido, alteração, teste e deploy.

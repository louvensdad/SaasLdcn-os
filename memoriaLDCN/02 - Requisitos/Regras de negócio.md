# Regras de negócio

- Toda solicitação relevante gera plano, status e resultado verificável.
- Toda alteração aplicada preserva uma versão restaurável.
- Produção não é alterada sem aprovação configurada.
- Credenciais nunca são expostas em texto puro.
- Projeto pronto exige preview funcional ou bloqueio explicado.
- A memória evita repetir perguntas já respondidas.

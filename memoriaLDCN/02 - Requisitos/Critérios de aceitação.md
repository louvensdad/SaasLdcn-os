# Critérios de aceitação

## Projeto web mínimo

- [ ] Criar projeto a partir de uma descrição.
- [ ] Fazer perguntas sem repetir respostas registradas.
- [ ] Exibir blueprint e plano.
- [ ] Gerar frontend, backend e banco.
- [ ] Iniciar sandbox sem terminal local.
- [ ] Abrir preview integrado.
- [ ] Mostrar logs e erros.
- [ ] Alterar, testar e criar nova versão.
- [ ] Restaurar versão anterior.

## Automação mínima

- [ ] Exibir gatilho, ações, condições e credenciais.
- [ ] Testar com dados simulados.
- [ ] Registrar falhas e retentativas.
- [ ] Exigir confirmação para ativação.

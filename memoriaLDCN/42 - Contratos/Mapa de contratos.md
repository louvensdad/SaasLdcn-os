# Mapa de contratos

Os contratos são a linguagem comum entre os módulos do MLTagente. Cada contrato define schema, versão, proprietário, produtores, consumidores, permissões, invariantes, erros e compatibilidade.

Regra: nenhum módulo deve consumir estrutura interna de outro módulo quando existir um contrato público.


Billing, Student Verification e eventos comerciais seguem [[Planos, assinaturas e controle de acesso]].

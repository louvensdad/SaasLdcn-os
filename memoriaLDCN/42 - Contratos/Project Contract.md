# Project Contract

## Objetivo

Definir identidade, tipo, Blueprint, versão ativa, estado e recursos de um projeto.

## Autoridade

Projeto é criado pelo Workspace; Orchestrator e engines atualizam estados por eventos; usuário aprova mudanças.

## Consumidores

Agentes, execução, preview, deploy, memória, billing, analytics e colaboração.

## Aceitação

- [ ] Projeto aponta para workspace, Blueprint e versão.
- [ ] Estado e proprietário da transição são registrados.

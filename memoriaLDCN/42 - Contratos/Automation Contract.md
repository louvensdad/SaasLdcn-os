# Automation Contract

## Objetivo

Definir fluxo, gatilho, conectores, credenciais, execução e política de falhas.

## Autoridade

Automation Engine escreve versões; usuário ativa; Scheduler dispara; Runtime executa; histórico registra.

## Aceitação

- [ ] Fluxo tem schema validável e versão.
- [ ] Credenciais são referências seguras.
- [ ] Retry, timeout e idempotência estão definidos.

# Transição do Prompt.md para Blueprint

## Objetivo

Converter intenção validada em planta técnica sem perder rastreabilidade.

## Fluxo

Prompt aprovado → mapear requisitos → criar Blueprint → apontar origem de cada seção → detectar lacunas → revisão → planejamento.

## Dependências

Contrato do Prompt.md, Mapa de Blueprint, Engine de Decisão e Planning Engine.

## Critérios de aceitação

- [ ] Toda seção do Blueprint aponta para Prompt.md ou decisão posterior.
- [ ] Suposições continuam marcadas.
- [ ] Conflitos bloqueiam a transição.

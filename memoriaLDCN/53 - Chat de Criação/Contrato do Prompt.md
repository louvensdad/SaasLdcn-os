# Contrato do Prompt.md

## Estrutura obrigatória

Identificação; ideia original; resumo interpretado; problema; público; objetivos; escopo confirmado; escopo sugerido; fora do escopo; fluxos; regras de negócio; dados; integrações; automação; requisitos não funcionais; preferências visuais; preferências técnicas; restrições; critérios de aceitação; suposições; dúvidas; riscos; estratégia de entrega; aprovação.

## Invariantes

O Prompt.md possui tipo, versão, status, autor, data, origem e projeto. A ideia original nunca é substituída por uma reescrita.

## Consumidores

Validador, Blueprint Engine, Planning Engine, agentes, custos e documentação viva.

## Critérios de aceitação

- [ ] Schema obrigatório validável.
- [ ] Campos pendentes não são confundidos com vazios.
- [ ] Compatibilidade do contrato é versionada.

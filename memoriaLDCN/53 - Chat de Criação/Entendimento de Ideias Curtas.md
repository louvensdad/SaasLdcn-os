# Entendimento de Ideias Curtas

## Objetivo

Compreender pedidos pequenos, informais, incompletos ou escritos com erros sem exigir prompt técnico.

## Processo

Normalizar mensagem → identificar entidades → detectar problema e resultado → identificar usuários → inferir funcionalidades → apontar riscos → criar hipótese → pedir confirmação simples.

## Regra

O MLTagente é responsável por estruturar a ideia; não deve exigir que o usuário escreva um prompt completo.

## Critérios de aceitação

- [ ] Mantém a intenção original.
- [ ] Distingue fato, hipótese e dúvida.
- [ ] Produz resumo compreensível.

# Descoberta Progressiva

## Objetivo

Aprofundar a especificação em rodadas curtas, perguntando somente o necessário para a próxima decisão.

## Fluxo

Hipótese inicial → perguntas de maior impacto → atualização do resumo → nova lacuna → confirmação → Prompt.md.

## Critérios de aceitação

- [ ] Máximo de três perguntas por rodada.
- [ ] Cada pergunta possui motivo e impacto.
- [ ] O usuário pode avançar com decisão padrão explícita.

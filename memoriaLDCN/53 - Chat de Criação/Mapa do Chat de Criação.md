# Mapa do Chat de Criação

## Objetivo

Transformar uma ideia curta, informal ou incompleta em uma especificação clara, validada e pronta para orientar a criação do sistema.

O usuário não precisa conhecer termos técnicos, arquitetura, banco de dados, APIs ou linguagens de programação.

## Fluxo principal

1. Usuário descreve a ideia.
2. Sistema identifica intenção, tipo de projeto e domínio.
3. Sistema consulta memória e contexto autorizados.
4. Sistema infere requisitos e identifica lacunas críticas.
5. Sistema faz somente perguntas necessárias.
6. Sistema apresenta resumo para confirmação.
7. Sistema gera e valida o Prompt.md.
8. Usuário aprova ou corrige.
9. Prompt.md alimenta o Blueprint.
10. Blueprint alimenta planejamento e geração.

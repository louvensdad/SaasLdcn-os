# Validação do Prompt.md

## Objetivo

Verificar se o Prompt.md é completo, coerente, rastreável e construível.

## Verificações

Campos obrigatórios, conflitos, referências, escopo, critérios, riscos, dados sensíveis, perguntas bloqueantes e compatibilidade com o tipo de projeto.

## Saída

Válido, válido com ressalvas ou bloqueado, sempre com evidências e correções sugeridas.

## Critérios de aceitação

- [ ] Validações são determinísticas quando possível.
- [ ] Cada bloqueio possui explicação.
- [ ] Prompt válido não garante viabilidade técnica sem validação posterior do Blueprint.

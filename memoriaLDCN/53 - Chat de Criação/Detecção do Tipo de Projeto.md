# Detecção do Tipo de Projeto

## Objetivo

Classificar a ideia em Web, Mobile, API, SaaS, Automação, Bot, Agente de IA, Desktop ou combinação.

## Fluxo

Entidades e verbos da ideia → candidatos → capacidades necessárias → confiança → confirmação → template de Prompt.md.

## Critérios de aceitação

- [ ] Classificação mostra confiança e alternativas.
- [ ] Projetos híbridos podem ter mais de um tipo.
- [ ] Usuário pode corrigir a classificação.

# Prompt.md para tipos de projeto

## Aplicação Web

Rotas, telas, usuários, responsividade, APIs, dados e critérios de navegador.

## Aplicação Mobile

Plataformas, navegação, permissões, offline, notificações e publicação.

## API

Recursos, contratos, autenticação, erros, limites, versionamento e observabilidade.

## SaaS

Tenancy, workspaces, planos, billing, permissões, isolamento e métricas.

## Automação

Gatilhos, ações, condições, credenciais, agendamento, retry e efeitos externos.

## Agente de IA

Papel, conhecimento, capacidades, ferramentas, políticas, avaliação e aprovação.

Cada variante usa o [[Contrato do Prompt.md]] e adiciona campos específicos sem quebrar o contrato comum.

# Detecção de Automação

## Objetivo

Identificar quando a ideia descreve gatilhos, ações, condições, integrações ou agendamentos.

## Fluxo

Pedido → sinais de automação → gatilho provável → ações → credenciais → confirmação → Prompt.md de automação.

## Critérios de aceitação

- [ ] Distingue aplicação interativa de fluxo automático.
- [ ] Identifica dados e efeitos externos.
- [ ] Ativação exige aprovação explícita.

# Modos de criação

## Modo Rápido

Ideia → inferência → resumo → confirmação → Prompt.md.

## Modo Guiado

Ideia → perguntas simples → sugestões → escolhas → Prompt.md.

## Modo Especialista

Ideia → arquitetura → contratos → requisitos técnicos → Prompt.md.

## Critérios de aceitação

- [ ] Modos compartilham o mesmo contrato de saída.
- [ ] Usuário pode mudar de modo sem perder contexto.
- [ ] Modo Rápido não esconde suposições; apenas reduz perguntas.

# Plataforma de Conhecimento

## Objetivo

Manter uma Wiki viva do projeto, atualizada a partir do código, Blueprint, APIs, fluxos, diagramas, decisões, glossário e FAQ.

## Fluxo

Alteração aprovada → detectar documentos afetados → gerar proposta → comparar com versão anterior → publicar após validação.

## Dependências

Blueprint, engenharia reversa, sistema de memória, versões, eventos e busca semântica.

## Critérios de aceitação

- [ ] Documentos apontam para a versão real do sistema.
- [ ] Conteúdo obsoleto é sinalizado.
- [ ] Usuário pode rastrear documento até código ou decisão.
- [ ] Atualização automática não sobrescreve revisão humana sem aprovação.
